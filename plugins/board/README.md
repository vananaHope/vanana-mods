# board (내 보드)

열린 결정, 할 일, 만든 링크를 옆 패널에 띄워 둔다. `/board`로 열고 닫는다.

- Claude가 `mcp__board__update` 도구로 할 일과 결정을 고친다. 보드는 시스템 프롬프트 끝(캐시 경계 뒤)에 붙는다.
- 답이 질문으로 끝나고 Claude가 그 턴에 결정을 올리지 않았으면, 그 질문 문장을 mod가 결정 칸에 옮긴다(모델 호출 없음). 이렇게 옮긴 결정은 사용자가 다음 프롬프트를 보내면 닫힌다. Claude가 올린 결정은 Claude가 `decide`로 닫을 때까지 남는다.
- 링크는 무언가를 만든 명령(`gh pr|issue|release|repo|gist create`, `gh pr|issue comment`, `git push`)과 만드는 MCP 도구의 결과에서만 모은다. 최근 12개.
- 패널 키: `l` 링크 비우기, `c` 완료 지우기, `x` 결정 모두 닫기.
- 설정(`/config`): `autoOpen`(기본 꺼짐). 켜면 빈 보드에 처음 항목이 생길 때 패널이 저절로 열린다.
- 서브에이전트는 보드를 고치지 않는다. 모든 값은 세션 동안만 남는다(`/clear`하면 빈 보드).
