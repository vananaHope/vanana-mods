# board (내 보드)

열린 결정, 할 일, 만든 링크를 옆 패널에 띄워 둔다. `/board`로 열고 닫는다.

- Claude가 `mcp__board__update` 도구로 할 일과 결정을 고친다. 보드는 시스템 프롬프트 끝(캐시 경계 뒤)에 붙고, 3단계 이상인 일은 보드에 올리라는 한 줄이 함께 붙는다.
- id(`t1`, `d1`…)는 지운 뒤에도 다시 쓰지 않는다. 보드에 없는 id를 가리키면 도구 결과에 그렇다고 알린다.
- 답이 질문으로 끝나고 Claude가 그 턴에 결정을 올리지 않았으면, 그 질문 문장을 mod가 결정 칸에 옮긴다(모델 호출 없음). "…할까요?" 다음에 후보 목록이 오는 답도 잡는다. 이렇게 옮긴 결정은 사용자가 다음 프롬프트를 보내면 닫힌다. Claude가 올린 결정은 Claude가 `decide`로 닫을 때까지 남는다. 사용자가 두 번 답할 동안 열려 있으면 패널에 흐리게 `(답 N번 지남)`을 붙이고, Claude에게는 이미 답을 들었으면 닫으라고 적는다.
- 링크는 무언가를 만든 명령(`gh pr|issue|release|repo|gist create`, `gh pr|issue comment`, `git push`), 만드는 MCP 도구, `Artifact` 도구로 게시한 페이지의 결과에서만 모은다. 최근 12개.
- 끝난 할 일은 `✓ N개 완료` 한 줄로 접혀 있다. 그 줄을 누르거나 `d`를 누르면 펼치고 다시 접는다. Claude에게 보내는 보드에도 끝난 할 일은 `Done (N): t1, t2` 한 줄로만 적는다.
- 패널 키: `d` 완료 펼치기·접기, `l` 링크 비우기, `c` 완료 지우기, `x` 결정 모두 닫기.
- 설정(`/config`): `autoOpen`(기본 꺼짐). 켜면 빈 보드에 처음 항목이 생길 때 패널이 저절로 열린다.
- 서브에이전트는 보드를 고치지 않는다. 모든 값은 세션 동안만 남는다(`/clear`하면 빈 보드).

## 설치

```
/plugin install board --marketplace vananaHope/vanana-mods
```
